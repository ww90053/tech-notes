docker/
├── container/ (容器管理：可省略 container 直接使用快捷指令)
│   ├── run ................. 建立並啟動一個新容器 (完整: docker run)
│   ├── start ............... 啟動已停止的容器 (完整: docker start)
│   ├── stop ................ 停止運行中的容器 (完整: docker stop)
│   ├── restart ............. 重啟容器 (完整: docker restart)
│   ├── rm .................. 刪除已停止的容器 (完整: docker rm，-f 可強制刪除)
│   ├── ps .................* 列出容器清單 (完整: docker ps，-a 包含已停止的)
│   ├── logs ................ 查看容器日誌 (完整: docker logs，-f 可即時追蹤)
│   ├── exec ................ 進入容器執行指令 (完整: docker exec -it [容器] bash)
│   ├── inspect ............. 檢查容器底層 JSON 資訊 (完整: docker inspect)
│   └── stats ............... 即時監控容器效能 (完整: docker stats)
│
├── image/ (映像檔管理)
│   ├── build ............... 依據 Dockerfile 建立映像檔 (完整: docker build -t [名稱] .)
│   ├── pull ................ 從遠端倉庫下載映像檔 (完整: docker pull)
│   ├── push ................ 將映像檔上傳至遠端倉庫 (完整: docker push)
│   ├── tag ................. 幫映像檔加上標籤/別名 (完整: docker tag)
│   ├── ls .................. 列出本地映像檔 (完整: docker image ls / 快捷: docker images)
│   ├── rm .................. 刪除本地映像檔 (完整: docker image rm / 快捷: docker rmi)
│   └── prune ............... 清理所有孤立、無標籤的映像檔 (完整: docker image prune)
│
├── network/ (網路管理)
│   ├── ls .................. 列出所有 Docker 網路 (完整: docker network ls)
│   ├── create .............. 建立一個新的虛擬網路 (完整: docker network create)
│   ├── connect ............. 將容器連接到指定網路 (完整: docker network connect)
│   ├── disconnect .......... 將容器從網路斷開 (完整: docker network disconnect)
│   └── inspect ............. 查看特定網路的詳細配置 (完整: docker network inspect)
│
├── volume/ (資料卷管理)
│   ├── ls .................. 列出所有本地資料卷 (完整: docker volume ls)
│   ├── create .............. 建立一個具名資料卷 (完整: docker volume create)
│   ├── inspect ............. 查看資料卷在宿主機的實際路徑 (完整: docker volume inspect)
│   └── prune ............... 刪除所有未被使用的資料卷 (完整: docker volume prune)
│
├── system/ (系統層級管理)
│   ├── df .................. 查看 Docker 資源佔用的硬碟空間 (完整: docker system df)
│   └── prune ............... 全系統大掃除 (完整: docker system prune，--volumes 連資料卷一起刪)
│
├── info .................... 查看 Docker 引擎全面資訊 (完整: docker info)
├── version ................. 查看 Docker 用戶端與伺服器版本 (完整: docker version)
│
└── compose/ (多容器編排：注意！現代語法為獨立指令)
    ├── up .................. 建立並啟動所有服務 (完整: docker compose up -d)
    ├── down ................ 停止並刪除所有容器與網路 (完整: docker compose down -v)
    ├── ps .................. 檢視目前專案下的容器狀態 (完整: docker compose ps)
    └── logs ................ 整合檢視專案下所有容器的日誌 (完整: docker compose logs)
