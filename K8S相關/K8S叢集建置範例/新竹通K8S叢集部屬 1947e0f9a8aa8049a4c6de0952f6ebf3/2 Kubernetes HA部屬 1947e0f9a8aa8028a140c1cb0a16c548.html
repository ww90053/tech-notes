2.Kubernetes HA部屬

每一個master節點都要設定，並且確定kubeadm、kubelet、kubectl套件已安裝完畢

先建立/etc/kubernetes/manifests/存放Static Pod的YAML檔

mkdir -p /etc/kubernetes/manifests/

HAProxy

建立HAProxy來提供Kubernetes API Server的負載平衡，在所有的Master節點建立目錄

mkdir -p /etc/haproxy/

接著新增/etc/haproxy/haproxy.cfg 設定檔

cat <<EOF > /etc/haproxy/haproxy.cfg
defaults
    mode                    http
    log                     global
    option                  httplog
    option                  dontlognull
    option http-server-close
    option forwardfor       except 127.0.0.0/8
    option                  redispatch
    retries                 3
    timeout http-request    10s
    timeout queue           1m
    timeout connect         10s
    timeout client          1m
    timeout server          1m
    timeout http-keep-alive 10s
    timeout check           10s
    maxconn                 3000

#---------------------------------------------------------------------
# main frontend which proxys to the backends
#---------------------------------------------------------------------
frontend kubernetes
    bind :8443
    option tcplog
    mode tcp
    default_backend kubernetes-master-nodes
#---------------------------------------------------------------------
# static backend for serving up images, stylesheets and such
#---------------------------------------------------------------------

#---------------------------------------------------------------------
# round robin balancing between the various backends
#---------------------------------------------------------------------
backend kubernetes-master-nodes
    mode tcp
    balance roundrobin
    stick-table type ip size 200k expire 30m
    stick on src
    option tcp-check
    server master01 10.1.235.11:6443 check fall 3 rise 2 #請自行更換成實際master ip
    server master02 10.1.235.12:6443 check fall 3 rise 2
    server master03 10.1.235.13:6443 check fall 3 rise 2
EOF
這邊會綁定8443作為API Server的Proxy

接著在新增一個路徑為/etc/kubernetes/manifests/haproxy.yaml的 YAML 檔來提供 HAProxy 的 Static Pod 部署，其內容如下：

cat <<EOF > /etc/kubernetes/manifests/haproxy.yaml
kind: Pod
apiVersion: v1
metadata:
  annotations:
    scheduler.alpha.kubernetes.io/critical-pod: ""
  labels:
    component: haproxy
    tier: control-plane
  name: kube-haproxy
  namespace: kube-system
spec:
  hostNetwork: true
  priorityClassName: system-cluster-critical
  containers:
  - name: kube-haproxy
    image: docker.io/haproxy
    resources:
      requests:
        cpu: 100m
    volumeMounts:
    - name: haproxy-cfg
      readOnly: true
      mountPath: /usr/local/etc/haproxy/haproxy.cfg
  volumes:
  - name: haproxy-cfg
    hostPath:
      path: /etc/haproxy/haproxy.cfg
      type: FileOrCreate
EOF

keepalived.yaml

建立keepalived.yaml

cat <<EOF > /etc/kubernetes/manifests/keepalived.yaml
kind: Pod
apiVersion: v1
metadata:
  annotations:
    scheduler.alpha.kubernetes.io/critical-pod: ""
  labels:
    component: keepalived
    tier: control-plane
  name: kube-keepalived
  namespace: kube-system
spec:
  hostNetwork: true
  priorityClassName: system-cluster-critical
  containers:
  - name: kube-keepalived
    image: docker.io/osixia/keepalived
    env:
    - name: KEEPALIVED_VIRTUAL_IPS
      value: 10.1.230.2
    - name: KEEPALIVED_INTERFACE 
      value: ensl60
    - name: KEEPALIVED_UNICAST_PEERS      
      value: "#PYTHON2BASH:['10.1.235.11', '10.1.235.12', '10.1.235.13']"
    - name: KEEPALIVED_PASSWORD
      value: crio
    - name: KEEPALIVED_PRIORITY
      value: "150"
    - name: KEEPALIVED_ROUTER_ID
      value: "51"
    resources:
      requests:
        cpu: 100m
    securityContext:
      privileged: true
      capabilities:
        add:
        - NET_ADMIN
EOF
  • KEEPALIVED_VIRTUAL_IPS：Keepalived 提供的 VIPs。可自定義，一個未被使用的IP，後續設定kubeadm init --control-plane-endpoint使用到
  • KEEPALIVED_INTERFACE：VIPs 綁定的網卡。請使用ip addr來查詢後更換實際主機網卡
  • KEEPALIVED_UNICAST_PEERS：其他 Keepalived 節點的單點傳播 IP。請修改成實際master節點IP
  • KEEPALIVED_PASSWORD：Keepalived auth_type 的 Password
  • KEEPALIVED_PRIORITY：指定了備援發生時，接手的介面之順序，數字越大，優先順序越高。這邊k8smaster1設為 150，其餘為100。
  • KEEPALIVED_ROUTER_ID：一組 Keepalived instance 的數字識別子。

最後如果有多台需要設定HA，master2及master3主機請重複上面動作，haproxy.cfg 、haproxy.yaml、keepalived.yaml建立，再執行以下語法

# k8smaster2跟k8smaster3請執行
sed -i '/KEEPALIVED_PRIORITY/{n;s/value: "150"/value: "100"/;}' /etc/kubernetes/manifests/keepalived.yaml
